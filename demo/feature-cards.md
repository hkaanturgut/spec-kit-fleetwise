# Audience feature cards

Let the room pick one for `/speckit-specify`. Each is a bounded slice of FleetWise.

| Card | Prompt |
| --- | --- |
| **Overdue dispatcher** (default) | Fleet managers need an overdue-maintenance dispatcher. Show vehicles that are overdue or due within 7 days, by mileage or by date. Suggest a work order for each vehicle with the right service type and a technician who has the required skill. A manager must approve a work order before it is booked. |
| Tenant maintenance dashboard | Each customer's fleet manager needs a dashboard of their own fleet's maintenance health: overdue, due soon, and completed this month, with no data from other customers. |
| Technician skill matching | When a work order is scheduled, only technicians in the same customer account who hold the required skill can be assigned. Show why a technician is not eligible. |
| Parts inventory alert | When a work order is scheduled, check whether the parts for that service type are in stock and warn the manager if they are not. |
